# 📊 Exploratory Data Analysis (EDA) on Retail Sales Data

## 📌 Project Overview

This project is part of the **Oasis Infobyte Data Analytics Internship (OIBSIP)**.

The objective of this project is to perform **Exploratory Data Analysis (EDA)** on a retail sales dataset to identify customer purchasing patterns, sales trends, product performance, and actionable business insights using Python.

---

## 🎯 Objective

- Perform initial data inspection.
- Clean and prepare the dataset for analysis.
- Analyze sales trends over time.
- Study customer demographics.
- Evaluate product category performance.
- Identify relationships between numerical variables.
- Generate business insights through visualizations.

---

## 🛠️ Technologies Used

- Python
- Google Colab (Jupyter Notebook)
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📂 Dataset

**Retail Sales Dataset**

The dataset contains information about:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## 📈 Exploratory Data Analysis Performed

### ✅ Initial Data Inspection

- Dataset Shape
- Data Types
- Missing Value Check
- First Five Records

### ✅ Data Cleaning

- Duplicate Record Check
- Missing Value Verification

### ✅ Descriptive Statistics

Calculated:

- Mean
- Median
- Mode
- Standard Deviation

for all numerical columns.

### ✅ Time Series Analysis

- Monthly Sales Trend
- Quarterly Sales Trend

### ✅ Customer Demographics Analysis

- Age Distribution
- Gender Distribution

### ✅ Product Analysis

- Best-Selling Product Categories
- Revenue by Product Category

### ✅ Correlation Analysis

- Correlation Matrix Heatmap

### ✅ Additional Visualization

- Average Sales by Gender and Product Category

---

## 📊 Key Insights

- Sales fluctuate across different months and quarters.
- Q4 generated the highest revenue.
- Clothing products recorded the highest quantity sold.
- Electronics generated the highest overall revenue.
- Customer purchasing behavior varies across age groups and gender.
- Product category significantly influences revenue generation.

---

## 💡 Business Recommendations

1. Maintain higher inventory levels for high-demand product categories.
2. Increase marketing efforts during high-sales months and quarters.
3. Promote lower-performing product categories through discounts and special offers.
4. Use customer demographic insights to create targeted marketing campaigns.
5. Monitor seasonal sales trends for better inventory and budget planning.
